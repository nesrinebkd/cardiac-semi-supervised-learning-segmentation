# Segmentation Predictions

The segmentation predictions generated by each method are stored 
as HDF5 (.h5) files and available on Google Drive.

## Viewing the Predictions

Predictions can be visualized using **[Fiji (ImageJ)](https://fiji.sc/)**:

1. Download and install Fiji
2. Open Fiji and load the `.h5` prediction file
3. Navigate through the datasets to visualize the segmentation outputs
